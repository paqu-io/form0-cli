# Support

## Documentation

Start with the [form0 documentation](https://docs.form0.dev) and the
[quickstart](https://docs.form0.dev/getting-started/quickstart). The recommended entry point for a
new form0 project is [form0-cli](https://github.com/paqu-io/form0-cli).

## Questions and bug reports

Search the [form0-cli issues](https://github.com/paqu-io/form0-cli/issues) before opening a new issue.
If you are unsure which form0 repository owns a problem, open it where you observed it; maintainers
can move or redirect it.

When reporting a bug, include the package version, runtime, the smallest reproducible schema or
project, expected behavior, and actual behavior.

For private or general support, email [support@paqu.io](mailto:support@paqu.io).

## Security

Do not report suspected vulnerabilities in a public issue. Follow this repository's
[security policy](./SECURITY.md) and use its private vulnerability-reporting link.
